V3 目前內容
17 個畫面沿用「收藏 → 找同行 → 雙方確認 → 路上互動 → 好友」的示例旅程。
探索與活動使用本次原創的「紙上散步」向量海報，實景照片保留作場地介紹。
加入收藏可輸入文字或連結；範例整理成活動卡，自訂內容保留原文並可補地點。
興趣可複選；共同興趣文字依目前選項顯示。
人物頁呈現示例人像、自介、攝影興趣與這次想去的活動。
同行畫面以地圖、人物、接送時間、額外時間與每人預估費用呈現；費用明細可展開。
申請者與接收者分別確認，畫面區分申請中、接受、撤回、未叫車與示例車程。
開放同行可切換還沒出發／已在途中，設定座位、可多花的時間與聊天意願。
好友猜題與車內題目使用真實台北照片作選項；揭曉後接一個可直接回答的聊天題目。
抵達頁呈現同行者、好友邀請及預估車資；對方接受後才變成好友。
我的頁面保留收藏、示例既有好友阿睿，以及小安的邀請狀態。
設計參考頁區分官方來源觀察與本案採用判斷，列出照片、原創海報、人像與地圖來源。

如何操作
左側選頁載入對應示例；中央畫面可操作；右側提供展示者說明與示範控制。
使用「重置示例操作」可從頭體驗。
探索 → 加入收藏 → 確認內容與興趣 → 加入收藏 → 活動 → 找同行 → 確認條件 → 我想一起搭。
手機頂端「示範控制」可切到小安處理申請、開始車程、抵達及接受好友。
也可另開相同網址的 #host 畫面接受申請；同源分頁會同步瀏覽器中的示例狀態。
接受同行 → 安排叫車（示例說明）→ 示範開始車程 → 選答案 → 示範揭曉 → 示範抵達 → 好友邀請。
「一起玩」可獨立使用。阿睿是示例既有好友；小安須另行邀請並接受。

實作邊界
這是可操作的前端設計原型。資料保存在目前瀏覽器的 yoxi-studio-v3 儲存項目。
同源分頁同步是本機狀態示範，沒有正式帳號、跨裝置多人服務或後端。
內容整理、推薦、媒合與遊戲答案為設定好的示例；未接真實 AI 內容解析或推薦服務。
地圖不是即時車隊；時間、路線、座位與車資不會由交通服務回傳。
未接正式派車、支付、優惠核銷、活動報名或朋友通知。
城市猜題為互動示例，沒有外部資料結算；題目與好友互動不代表正式多人遊戲服務。
官方歷史乘車資料未用來推測人物興趣、即時位置或沿途軌跡。
