Run this folder using a local HTTP server, or deploy it as static files. The WebGL module requires HTTP(S), rather than opening index.html through file://.

The actual playable 30-second Run uses local Three.js and original procedural bear/collectible assets. Touch buttons, swipes, arrows/space, pause and retry are implemented. First completion unlocks the leaf bookmark. Equipped items carry into Run and the result screen. Scores and selections persist in this browser under a V7-specific key.

Mileage, rides, people and rival scores are demonstration records. Finishing the sample arrival adds 3.8 km, 15 minutes and Zhongshan once. Monthly totals and city districts are derived from one shared trip list. Run points never add riding distance. There is no production ride sync, online leaderboard, verified identity, reward redemption or payment backend.

The map and 3D city are thematic illustrations, not exact boundaries, real driving tracks or navigation.

qa-v7 contains actual UI captures; unchanged V6 screen captures are reused where their UI remains identical. Public reference and integration pages identify examples and limitations. The current PDF/PPTX was reviewed for placement; it was not edited.
