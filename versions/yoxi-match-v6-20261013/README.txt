本版重點
從活動找出門的理由，從順路的行程找到同行的人，再用大家選的歌開話題。
沿用真實的「JINS 野餐我 PET 你・滾草皮音樂市集」。新增常聽歌曲、這趟歌單、一起唱、旅程歌單與同行偏好。
姓名頭像與介紹放在行程裡。自己為小晴，原乘客為小安；兩人均為女性示例人物。朋友頁另有既有好友阿睿的活動邀約。

主示範路徑
探索 → 看活動 → 選同行偏好 → 找順路的車 → 看同行介紹 → 確認條件 → 申請加入 → 原乘客確認 → 這趟歌單 → 抵達與收藏歌單。
常聽的歌可從興趣頁設定。加入行程前先確認時間、上車地點、費用與同行偏好，歌曲共同點提供聊天材料。
旅途中可以選歌、問對方要不要一起唱，或回答一題。安靜搭車也有自己的選項。
邀約、收藏、選歌可以各自使用。朋友邀約採複製內容與連結，由使用者自行分享；程式不會傳送訊息。
抵達後可送出好友邀請；接受狀態需另一方確認。示範控制可推進另一方回覆、開始車程、抵達及接受好友。
左側選頁載入對應情境；同源分頁能同步此瀏覽器的示例狀態；重置可重新開始。

音樂怎麼用
本人從六首示例曲目選 1–3 首常聽的歌。搜尋只涵蓋這六首歌，不是完整音樂搜尋。
共同歌曲由相同歌曲 ID 求交集；小安的選歌為設定好的示例。這是真實執行的本機比對，不是模型推論，也未讀取 Spotify／Apple Music 帳號或聆聽紀錄。
這趟歌單標出誰加的歌，可以加入、移除和按讚。對方的既有歌曲與反應為示例資料，沒有另一位使用者即時加歌。
「一起唱」分開記錄本人意願、對方意願及車內播放許可。換歌後須重新等對方回覆；雙方願意且車輛開放時，才顯示該畫面的外部歌曲入口。
對方回覆與車內許可由展示者控制，未連接車輛設備。喜歡同一首歌或勾選一起唱，不等於已取得所有同意。
歌曲開啟官方 Apple Music 頁面；沒有 App 內音訊、串流、卡拉 OK 音軌、歌詞、麥克風或錄音。Apple Music 的實際播放由外部服務處理。
旅程後可把這趟歌單存到目前瀏覽器，並回到朋友頁安排下一次出門。

同行偏好
車上氣氛：安靜搭車、輕鬆聊聊、一起聽歌、一起唱，或都可以。
先篩行程日期、路線和時間，再確認偏好；歌曲共同點不能取代行程條件。
「女性乘客同行」只篩同行乘客，駕駛性別未指定。性別為示例本人填寫資料，不從姓名、歌曲或興趣推論。
本版尚未接身分驗證；女性同行選項不構成身分查核或安全保證。
行程成立後，條件以申請時快照為準；修改下一次搜尋的偏好不代表已變更雙方確認的安排。

行程與費用示例
日期：10/17（六）。13:30 台北車站東三門 → 13:45 花博圓山園區。
搜尋可改成 14:00 或民權西路站，呈現沒有符合候選的情況。
兩人同行：整趟預估 NT$300 ÷ 2 = NT$150，再減示例優惠 NT$30，每人 NT$120。
時間、座位、車資、優惠與乘客都是示例，不是正式報價或即時派車資料。
地圖是台北車站往北到圓山的地理示意；途中接人點示意在民權西路附近。非導航路線或即時車隊。

原有話題互動
出發前：「到現場，你想先做什麼？」選聽音樂、逛市集、找地方坐。
搭車時：「聽到喜歡的歌，你會？」選跟著唱、跟著點頭、先找歌名。
每人選自己的答案，揭曉後接一句聊天話題；沒有正確答案、分數、配對率、賭注或城市預測。
朋友頁對方為阿睿，行程中為小安；答案是示例固定內容，沒有 AI 代答。
每題可跳過。回答不影響搭乘資格、優惠或好友邀請。

功能狀態
本機互動：收藏、示例整理、興趣、六首曲目搜尋與選擇、共同歌曲交集、同行偏好、條件篩選、邀約複製、加入／接受／撤回、開放座位、歌單、唱歌意願、問題與好友邀請。
資料存於目前瀏覽器的 yoxi-studio-v6，沒有正式帳號或跨裝置多人後端。
文字／連結解析、推薦和同行候選為設定好的示例；尚未接正式 AI、通知、派車、付款、活動報名或優惠核銷。
官方歷史乘車資料未用來推測興趣、人格、性別、即時位置或沿途軌跡。
