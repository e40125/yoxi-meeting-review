P7

平常玩一局，路上多個話題。

原頁：PLAY：不搭車，也能參與的城市趣味互動。

放大一張 Run 畫面，旁邊節錄同路線名次。保留歌單或破冰的一個例子。大稻埕直接玩、圓山可先試跑，交代非搭車日也能使用。

P9

去過圓山，隔天再跑圓山。

原頁：從一則收藏，到真正出發。

主影片：探索活動 → 找同行、雙方確認 → 路上互動 → 抵達圓山 → 新足跡、花朵與我的路線 → 隔天玩圓山。

全程沿用同一個地方和同一隻熊。加入「隔天」的轉場，讓 Run 回答再次打開的理由。這是一種使用情境，各入口仍可獨立使用。

P13

每次出發，都有東西留下。

原頁：讓每次互動，累積下一次探索的價值。

以里程、城市足跡及圓山花朵替換抽象循環。再指出「我的圓山路線」如何接到下次遊玩與朋友挑戰；旅程歌單與經雙方同意的好友關係繼續保留。

P11

行程留下紀錄，遊戲另外計分。

原頁：讓 AI 理解興趣，也讓使用者掌握自己的資料。

距離、時間與起訖座標可支援統計和到訪區域；圓山場景按抵達區域對應。此 demo 使用示例帳號及行程，沒有用歷史 CSV 還原沿途軌跡。
