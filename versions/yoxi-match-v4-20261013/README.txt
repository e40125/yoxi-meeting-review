這版怎麼走
先看活動，再約朋友或找順路的車。同行頁先說日期、時間、接點、座位與費用；人物改成姓名頭像和簡短介紹。
朋友頁展示既有好友阿睿的市集邀約。邀朋友可複製邀約與連結，由使用者自行分享，程式不會傳送訊息。
找順路的車仍是小安與阿哲兩人同行的示例；每人預估 NT$150（分攤 NT$180，示例優惠減 NT$30）。
收藏、輸入內容、修改興趣、條件篩選、雙方確認、撤回、開放座位、抵達與好友邀請均保留。

互動機制
移除城市預測入口，獨立好友猜題不再是主入口。
「你選哪個」有兩題：到市集想先逛什麼；什麼會讓你路上停下來拍照。
各自選自己的答案，再看彼此選擇。揭曉後提供一句聊天話題；沒有正確答案、分數或配對率。
朋友頁進入時，對方是既有好友阿睿；確認同行後進入時，對方是小安。對方答案都是事先寫好的示例。
每題可跳過或返回。回答不影響收藏、同行資格、優惠或加好友。

操作路徑
日常：探索 → 朋友的邀約 → 看活動／複製邀約 → 出發前選一題 → 自己選答案 → 一起看答案。
同行：活動 → 找順路的車 → 確認條件 → 申請加入 → 原乘客接受 → 行程確認。
確認後可先聊一題，也可安排叫車。展示者開始示例車程後，能進入路上話題；抵達後可另行邀請成為好友。
左側選頁會載入對應示例；右側或手機「示範控制」可切換原乘客、開始車程、抵達及接受好友。
相同來源的瀏覽器分頁可同步示例狀態；使用重置按鈕可重新開始。
