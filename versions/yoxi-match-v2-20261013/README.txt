本輪改動
17 頁採用更短的白話文、明確按鈕、選取狀態與固定導覽。
探索以實景照片、日期、名稱、地點呈現；活動與同行者共用同一情境。
行程先顯示接送時間與每人總額；費用明細可展開。
好友猜題使用大題目、三個選項；車內題目保留個人答案與接續話題。
補上空白、未選、等待、已確認、已送邀請等互動狀態。
設計參考頁區分官方介面模式與本案設計判斷。

如何操作
左側選頁會載入對應示例；中央畫面可操作；右側為展示者說明。
使用「重置示例操作」從頭體驗。
探索 → 加入收藏 → 確認內容與興趣 → 存到收藏 → 活動 → 找同行 → 確認條件 → 申請。
手機頂端「示範控制」可切到小安處理申請、開始車程、抵達及接受好友。
也可另開相同網址 #host 接受申請，原分頁會同步更新。
確認 → 安排叫車 → 示範車內畫面 → 選答案 → 示範雙方揭曉 → 示範抵達 → 好友邀請。
「一起玩」可以獨立使用。阿睿是示例既有好友；小安須另行邀請並接受。
