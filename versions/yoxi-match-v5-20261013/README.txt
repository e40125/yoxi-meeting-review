本版重點
主活動改為真實的「JINS 野餐我 PET 你・滾草皮音樂市集」。探索頁先呈現活動氣氛，再列日期、地點與免費入場；朋友頁以阿睿的「週六去花博聽音樂？」邀約開始。
活動詳情提供邀朋友、找順路的車兩個動作。人物仍是姓名頭像和簡短介紹，放在行程脈絡中。
邀約採複製內容與連結，由使用者自行分享；程式不會傳送訊息。

主示範路徑
探索 → 看活動 → 找順路的車 → 確認條件 → 申請加入 → 原乘客確認 → 選擇是否聊一題 → 抵達。
確認行程後，可先選出發前的問題，也可安排叫車。示範控制可推進車程、抵達及接受好友。
朋友邀約與收藏也能獨立使用。抵達後可自行送出好友邀請，接受狀態需另一方確認。
左側選頁載入對應示例；同源分頁能同步示例狀態；重置可重新開始。

行程與費用示例
日期：10/17（六）。13:30 台北車站東三門 → 13:45 花博圓山園區。
搜尋可改成14:00或民權西路站，呈現沒有符合候選的情況；已確認的行程保留原始快照。
兩人同行：整趟預估 NT$300 ÷ 2 = NT$150，再減示例優惠 NT$30，每人 NT$120。
這些時間、座位、車資、優惠與乘客都為示例，不是正式報價或即時派車資料。
地圖改為台北車站往北到圓山的地理示意；途中接人點示意在民權西路附近。非導航路線或即時車隊。

互動機制
出發前：「到現場，你想先做什麼？」選聽音樂、逛市集、找地方坐。
搭車時：「聽到喜歡的歌，你會？」選跟著唱、跟著點頭、先找歌名。
每人選自己的答案，揭曉後接一句聊天話題；沒有正確答案、分數、配對率或城市預測。
朋友頁的對方是既有好友阿睿；行程中的對方是小安。對方答案事先寫在示例中，沒有另一人即時作答或AI代答。
每題可跳過，回答不影響搭乘資格、優惠或加好友。正式多人作答與分享控制尚未實作。
